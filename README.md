## MLO 为什么没有一个月付价

它是一款老牌的待办与任务管理软件，特点是无限层级的任务树和自定义过滤器。你可以用 GTD，也可以按自己的方式搭一套体系，任务之间能设前后依赖，提醒可以按位置触发。
